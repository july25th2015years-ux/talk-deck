# TalkDeck（トークデッキ）💞

> **付き合って2ヶ月のふたりがもっと親密になる、ちょっと踏み込んだ100の質問デッキ**

2人でスマホ画面を見ながらカードを引き、交代で答え合うことで、お互いの本音・価値観・お金観・生活スタイル・未来のイメージまで楽しく深掘りできるカップル向けトークカードWebアプリです。

---

## ✨ 主な特徴

1. **重複なし・厳選100問の6カテゴリ構成**
   - 💕 **ふたりの関係・本音**（17問）
   - 🦁 **お金・リベシティ・価値観**（17問）— 5つの力・価値観マップ・使う力・家計観など
   - 🏡 **生活スタイル・相性**（17問）— 連絡頻度・1人時間・同棲ルールなど
   - 🌙 **過去・素の自分**（17問）— 恋愛観・家族観・弱みや甘え方など
   - 🚀 **これからの未来**（16問）— 半年後〜数年後の夢・結婚観・働き方など
   - 🔥 **ドキッと・距離感**（16問）— 愛情表現・距離感・スキンシップの好みなど

2. **深掘りヒント＆会話のコツ（カード裏面）**
   - すべての質問に、続けて聞ける3つの深掘り質問・盛り上がるコツ・大切にしたいポイントを収録
   - 100問を1周し終わるまで同じカードが重複しないシャッフル＆進捗バー付き
   - お気に入り保存・履歴戻る機能対応
